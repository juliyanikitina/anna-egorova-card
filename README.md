# Цифровая визитка Анны Егоровой

Одностраничная персональная визитка руководителя направления факторинга по Сибири и Дальнему Востоку.

Сайт содержит быстрые действия: звонок, переход в MAX, письмо по электронной почте и сохранение готового контакта в формате vCard. Перед скачиванием открывается карточка с фотографией и всеми контактными данными; фотография также встраивается в vCard.
